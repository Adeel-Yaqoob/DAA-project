# DAA-project
Celebrity Puzzle Game
Celebrity Puzzle Game is an interactive GUI-based game developed in Python using Tkinter. The game is based on the “Celebrity Problem Revisited” puzzle from the book *Algorithmic Puzzles*. In this game, the player must identify the hidden celebrity in a group of people by asking logical questions such as “Does Person A know Person B?”. A celebrity is defined as a person who is known by everyone but does not know anyone else.

The project implements both Brute Force and Efficient (Decrease-and-Conquer) algorithms to solve the puzzle and compare their performance. The game also includes a score system, hidden relationship matrix, and user-friendly graphical interface for better interaction and understanding of algorithm concepts.
